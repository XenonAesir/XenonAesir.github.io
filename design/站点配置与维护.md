## 一、部署（Vercel）

### 1. 首次部署

1. 打开 <https://vercel.com/new>，用 GitHub 账号登录
2. 授权 Vercel 访问 `XenonAesir/my-website` 仓库
3. 选中该仓库 → **Import**
4. 框架会被自动识别为 Next.js，构建命令不用改：
   - Install Command：`pnpm install`（有 `pnpm-lock.yaml`，自动识别）
   - Build Command：`pnpm build`
5. 点 **Deploy**，约 1 分钟完成

### 2. 环境变量（部署后必须补）

| 变量 | 值 | 作用 |
|---|---|---|
| `NEXT_PUBLIC_SITE_URL` | `https://你的正式域名` | RSS、sitemap 里的绝对地址 |

Vercel 项目 → **Settings → Environment Variables** 添加，然后 **Redeploy** 一次。
不设的话，RSS 和 sitemap 里全是 `http://localhost:3000`。

### 3. 之后的发布流程

```
改内容 → git commit → git push → Vercel 自动构建上线
```

- 推 `main` 分支 → 生产环境更新
- 推其他分支 / 开 PR → 生成一个预览地址，不影响正式站

## 二、域名现状

| 域名 | 状态 | 说明 |
|---|---|---|
| `xenonaesir.github.io` | ✅ 在线 | **指向 2022 年的 Hexo 旧站**，不是这个新站 |
| `<项目名>.vercel.app` | ❌ 还没有 | 首次部署后自动获得 |
| 自定义域名 | 未知 | 取决于是否在阿里云等处注册过 |

**关键一点**：`xenonaesir.github.io` 属于 GitHub Pages，只能服务那个仓库，**不能**指给 Vercel。
想用免费域名，就用 Vercel 分配的 `.vercel.app`；想要自己的域名，去注册商买一个再绑到 Vercel。

绑定自定义域名：Vercel → Settings → Domains → 输入域名，
**以面板当场给出的 DNS 记录为准**（子域名通常是 CNAME 到 `cname.vercel-dns.com`，
根域名是 A 记录）。Vercel 调整过这些值，不要照抄旧教程。

## 三、内容（最常见操作）

### 1. 新增一篇文章

在 `content/posts/` 下新建 `英文-slug.mdx`，文件名就是 URL：`my-post.mdx` → `/blog/my-post`。

```yaml
---
title: 文章标题
date: 2026-11-04
summary: 列表页显示的一句话摘要
tags: [随笔, 技术]
draft: false
---

正文从这里开始。
```

### 2. frontmatter 字段

| 字段 | 必填 | 类型 | 说明 |
|---|---|---|---|
| `title` | ✅ | 文本 | 不能为空，否则构建报错 |
| `date` | ✅ | `YYYY-MM-DD` | 写错格式会报错（zod 校验） |
| `summary` | ❌ | 文本 | 列表页摘要，默认空 |
| `tags` | ❌ | 列表 | 用于标签筛选，默认空 |
| `draft` | ❌ | 布尔 | `true` 时只在 `pnpm dev` 可见，构建产物里没有 |

### 3. 正文支持什么

| 语法 | 示例 | 说明 |
|---|---|---|
| 标准 Markdown | 标题、列表、引用、链接、图片 | 基础 |
| GFM 表格 | `\| a \| b \|` | 第二行冒号控制对齐 |
| 任务列表 | `- [x] 已完成` | 复选框是浏览器原生样式 |
| 删除线 | `~~文字~~` | |
| 脚注 | `文字[^1]` + `[^1]: 说明` | 文末会自动生成列表 |
| 行内公式 | `$E = mc^2$` | KaTeX |
| 块级公式 | `$$ ... $$` | 支持矩阵、积分 |
| 代码高亮 | ` ```ts ` | 浅色 github-light / 深色 github-dark |
| 内联 SVG | `<svg>...</svg>` | 图表用主题变量取色，自动适配深色 |

### 4. 草稿

- 开发时：`pnpm dev` 能看，列表里带「草稿」标记
- 生产时：`pnpm build` 后，从列表、详情页、RSS、sitemap 全部消失
- 示例文件：`content/posts/draft-example.mdx`

## 四、外观

### 1. 配色

全部集中在 `app/globals.css`：

| 位置 | 作用 |
|---|---|
| `:root { ... }` | 浅色模式色板（纸白蓝） |
| `.dark { ... }` | 深色模式色板（IB 原版海军蓝） |

关键变量：

| 变量 | 浅色值 | 深色值 | 用在哪 |
|---|---|---|---|
| `--background` | `#f5f8fd` | `#181e32` | 页面底色 |
| `--foreground` | `#1c2942` | `#e0e6f2` | 正文 |
| `--primary` | `#3f6f9e` | `#72a8d8` | 强调、链接、进度条 |
| `--muted-foreground` | `#6b7d9e` | `#7e90b2` | 次要文字 |
| `--border` | `rgba(80,128,176,.18)` | `rgba(165,188,230,.2)` | 描边 |
| `--radius` | `0.875rem` | — | 全局圆角基数 |

改色只改这两块，所有组件（shadcn、卡片、导航、公式）自动跟随。

### 2. 字体

在 `app/layout.tsx` 用 `next/font/google` 加载 4 个字体：

| 字体 | CSS 变量 | 用途 |
|---|---|---|
| Geist | `--font-geist-sans` | 正文 |
| Geist Mono | `--font-geist-mono` | 代码 |
| Cormorant Garamond | `--font-cormorant` | 标题衬线 |
| Great Vibes | `--font-great-vibes` | 签名手写体 |

中文没有前两者的字形，会回落到 `--font-heading` 里定义的宋体栈（`app/globals.css` 的 `@theme inline` 块）。

### 3. 首屏文案与署名

`app/page.tsx`：

| 想改 | 改哪里 |
|---|---|
| 项目名（现在是占位 `Project` / `Name`） | `<h1>` 里两个 `<span>` |
| 眉题 `Personal Site · Est. 2026` | `<p className="rise ...">` |
| 署名 `DESIGNED BY Xenon Aesir` | `<span className="home-credit-sui">` |
| 标语「写代码，也写字。」 | 第一个 `<p className="rise mt-10 ...">` |
| 说明文字 | 第二个 `<p>` |
| 社交链接 | 文件顶部 `socials` 数组 |
| 首页显示几篇文章 | `getAllPosts().slice(0, 3)` 里的 `3` |

### 4. 导航

`components/site-header.tsx`：

| 项目 | 当前值 | 位置 |
|---|---|---|
| 导航高度 | `h-20`（80px） | `NavContent className` |
| 常驻导航出现时机 | 首屏导航离开视口时 | `IntersectionObserver` |
| 背景透明度 | `bg-background/80` | 常驻 header |
| 淡入时长 | 0.8s / 0.5s | `globals.css` 的 `.fade-in`、`transition-opacity` |

分隔线样式：`globals.css` 的 `.nav-rule`（中央 22% 浓度，两端透明）。

### 5. 动效开关

`app/globals.css` 里 `.rise`（首屏逐块淡入）和 `.fade-in`（导航淡入）都带：

```css
@media (prefers-reduced-motion: reduce) { ... animation: none; }
```

系统开了「减少动态效果」会自动关闭，不需要额外配置。

## 五、行为

| 开关 | 当前值 | 位置 | 说明 |
|---|---|---|---|
| 每页文章数 | `5` | `components/blog-browser.tsx` 的 `PAGE_SIZE` | 文章 ≤ 5 篇时不显示翻页 |

## 六、SEO 与分发

| 路由 | 文件 | 内容 |
|---|---|---|
| `/feed.xml` | `app/feed.xml/route.ts` | RSS 2.0，只含标题/链接/日期/摘要 |
| `/sitemap.xml` | `app/sitemap.ts` | 首页 + 列表 + 每篇文章 |
| `/robots.txt` | `app/robots.ts` | 允许全部抓取，指向 sitemap |

三者都在构建时静态生成，草稿文章不会出现。站点地址读 `lib/site.ts` 的 `SITE_URL`。

## 八、已知限制

| 限制 | 现状 | 什么时候需要处理 |
|---|---|---|
| 搜索是纯客户端过滤 | 首次加载带上全部文章元数据 | 文章到几十篇时换 Pagefind |
| 分页每页 5 条 | 3 篇文章看不出效果 | 文章超过 5 篇自动出现 |
| Great Vibes 只有拉丁字形 | 签名写中文会掉回宋体 | 想写中文名时换字体或画 SVG |
| 脚注标题是英文 `Footnotes` | remark 自带 | 介意的话在 CSS 里隐藏或替换 |
| 任务列表复选框是原生样式 | 未美化 | 需要统一视觉时再改 |
| 深色模式没有跟随系统 | 默认浅色，手动切换 | 想跟随系统就把 `defaultTheme` 改成 `"system"` |
| `xenonaesir.github.io` 仍是旧站 | 两个站并存 | 想合并时需要替换旧仓库内容 |
